# 双端日志记录器

这是电脑端离线收集工具，不安装新软件，不改相机或电控，不打开COM，不发送动作命令。不是实时UART抓线或自动读取MaixVision窗口。

## 按这五步使用

1. 双击 `启动双端日志记录器.bat`。使用现有 `E:\setup\anaconda\envs\yolo_train\python.exe`，无需激活训练环境。
2. 连接MaixVision与手机BLE，先开始两端日志记录。保留相机启动信息、MCU的READY/DIAG固件号；不要混入多次重启。
3. 优先用电控 **33静止接收诊断**：选择33后按g开始扫码，再识别物体。结束按g/a/0关闭本地接收。**不要误选31/32/34运动测试；保持电机/激光安全隔离。** 工具自身不会发送这些指令。
4. 测试后复制MaixVision **DEVICE** 面板本轮全部文本，点左侧“粘贴整段日志”。从手机导出BLE `.txt`，点右侧“导入TXT文件”。若手机尚未导出，可先粘贴文本。填写设备版本、模式和现象。
5. 点“保存本轮双端日志（不上传）”。路径显示在窗口底部。关闭工具前必须保存；每次保存创建唯一目录，不覆盖旧测试。

如果缺一端日志，工具仍允许保存，但不能据此判断双端链路。相机控制台必须能看到 `[UART RX]`/`[UART TX]`；现有App的业务TX默认每10帧打印一次，没有日志不等于没有发送。

## 保存在哪里

本工具目录下 `sessions/test_日期_时间_随机码/`，包含：

- `camera_raw.txt`：相机原始文本。
- `mcu_ble_raw.txt`：电控BLE原始文本。
- `rx_tx.csv`：来源、方向、写入状态、解码和警告。Excel公式危险前缀会加引号，完整原文仍保留于TXT/JSONL。
- `events.jsonl`：逐条结构化观察；解码60请求、63任务、61 ACK、62包装、01物体和53三码。相机RX碎片按顺序拼接。
- `核对报告.md`：观察统计、MCU累计快照和证据边界。
- `metadata.json`：电脑收集时间、测试说明和输出文件SHA-256。

RX/TX方向相对于日志所属设备。TX `complete`只说明相机驱动报告完整写入，不能证明MCU收到；partial/blocked里的HEX是整帧发送意图，不能当作完整发出的数据。MCU `VW`为累计快照，不能相加；`VR hex`仅为缓存前缀，可能截断，不当作完整帧检验。

## 测试后再上传

`sessions/`被Git忽略；工具不联网、不自动提交或上传。把同一轮保存目录路径发给Codex，核对相机RX请求、TX ACK/结果与MCU累计状态。确认需上传后，先清理个人标识/隐私，再仅发布该轮审查过的证据与交接结论。主机CRC核对不等于实体链路或机器人动作验收。

命令行导入也可使用（无需GUI）：

```powershell
& 'E:\setup\anaconda\envs\yolo_train\python.exe' -B .\uart_log_collector.py --camera .\相机.txt --mcu .\电控.txt --note '33静止诊断，同一轮，无重启'
```

开发验证：`python -B -m unittest discover -s tests -v`。测试使用合成帧，不是实机日志。
