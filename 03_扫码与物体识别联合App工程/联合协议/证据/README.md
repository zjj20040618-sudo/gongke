# 证据目录

本目录仅定义交付规则，**目前没有现场原始日志或已通过的验收记录**。后续由视觉组、电控组采集并放入对应的受控位置，不要改写原始记录。若日志包含个人信息或凭证，先按团队规定脱敏后再纳入版本控制。

最少保留：采集时间、设备与固件/模型版本、双方代码提交号、串口参数、原始收发字节或文本、帧号/时间戳、对应图像编号、采集工具与复现步骤、文件 SHA-256。R0.3 需要合法帧、截断帧、错误校验/非法行、非法编号、连续两帧及坏帧后的合法帧。后续 G1～G5 的日志、图片和测量表按门分别归档。

建议文件名用 `G0_视觉_TX_日期时间.bin`、`G0_电控_RX_日期时间.bin`、`G0_采集记录.md` 等，勿覆盖同名旧文件。采集记录注明原始日志与测试生成样例的区别；不要把 synthetic/演示数据标成现场证据。
