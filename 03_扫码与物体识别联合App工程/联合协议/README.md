# 视觉电控联调工程

状态：**G0 协议基线待决策**。本工程依据同级目录的《视觉电控联调_SDD规范书_2026-09-30.docx》建立，先用于取证、选择唯一协议和记录逐阶段验收，不是可直接烧录或上传的完整联调程序。

## 先看哪里

1. 阅读 `G0_协议现状对照.md`，核对实际源码与原说明的差异。
2. 视觉组和电控组各自提供当前代码提交号、设备/模型版本、**未手工改写的原始 UART 收发记录**，存放路径写在 `证据/README.md` 所列清单里。不要把演示程序生成的数据当成现场样帧。
3. 双方填写并签署 `G0_协议基线决策单.md`：选 A（ASCII）、B（二进制）或新版本 C；逐字段确定格式、编号、长度、校验、异常行为及迁移办法。
4. 基线签署后再为 R0.3 提供正例、截断、校验错误、非法编号、连续两帧的双端回放；使用 `验收记录模板.md` 记录命令、退出状态和原始证据。G0 通过后才进入 G1。

## 当前可确认的入口

- 视觉端：`../03_扫码与物体识别联合App工程/qr_object_app/main.py`；当前二进制组包在同目录 `protocol.py`。
- STM32 端：`../02_STM32视觉UART通信工程/stm32project`；参考解析器在 `../02_STM32视觉UART通信工程/协议参考源码/`。
- 接线候选：STM32 USART2 `PD5=TX` 接视觉 RX，`PD6=RX` 接视觉 TX，共地，3.3V TTL、115200、8N1；进入 G1 时仍需实测确认。

## 阶段门

| 门 | 工作 | 退出证据 |
|---|---|
| G0 | 选择 A/B/C，冻结字段和编号 | 双方签署决策单、真实样帧及正反例回放 |
| G1 | 接线、电平、收发和坏帧恢复 | 接线照片、电平记录、回放日志 |
| G2 | 二维码/目标语义及失效输入 | 每类正反样例、无误动作记录 |
| G3 | 找球、转向、找桶及多目标时序 | 连续日志回放、无跨阶段旧帧 |
| G4 | 固定机构后的坐标与工作点标定 | 左右、远近测量与复测记录 |
| G5 | 整合回归及受控现场放行 | G0～G4 全部通过、负责人确认 |

G0 未签署前，不修改 `02`、`03` 中正在使用的协议实现，不混用 A/B 字段，不新建 `SET,bucket` 的猜测编码。装车标定和 G5 未通过前，**视觉自动放行保持关闭**；只允许受控台架验证。新工程没有创建项目 `AGENTS.md`，协议基线确认后再由负责人决定是否加入项目规则。
