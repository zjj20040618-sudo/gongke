# SDD 单轮验收记录模板

复制本页后每个子需求单独填写，不要把多个未验证需求合写成“完成”。状态只用：已证实、待验证、待决策、已通过、未通过。

| 项目 | 本轮记录 |
|---|---|
| 门 / 需求编号 | G__ / R__.__ |
| 执行日期、执行人、验收人 | 待填写 |
| 已签署协议基线版本与双方提交号 | 待填写；G0 前填“待决策” |
| 设备、固件、模型与串口设置 | 待填写 |
| 输入原始日志、图像编号及 SHA-256 | 待填写 |
| 预期输出或状态；失败复现 | 待填写 |
| 本轮修改的文件 | 待填写；纯取证填“无” |
| 验证命令、退出码及实测结果 | 待填写 |
| 日志、截图、回放脚本路径 | 待填写 |
| 受影响的上一阶段需求与复测结果 | 待填写 |
| 未决问题、负责人、截止点 | 待填写 |
| 结论与签署 | 待验证；签名/日期待填写 |

无原始证据、失败样例或安全条件不满足时，不得写“已通过”。G4 标定须附原图与工作点测量；G5 须附全阶段门结果及安全负责人确认。
