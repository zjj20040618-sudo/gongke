## 最近一次功能代码改了什么

以下是上一轮已上传代码的说明，不是本次又改了一遍。

1. **配套新版视觉接收**：`App/proto.c` 接受9541模型ID0～9，补ID0→腰鼓、ID2→圆锥、ID9→黑桶；10及以上仍拒绝整包。QR仍是三个1～3的数字，分别选择球色、靶色、人质形状，不是模型ID或摆放位置。两种人质按队友训练别名适配，须用赛题实物验证。
2. **新增静止诊断33**：`App/test.c` 及 `App/robot.c` 配套缓存、回传。手机发送 `33`，再 `g`，自动请求QR；收到本轮确认及合法扫码后切OBJECT，每秒ASCII回传所选球/靶/人质/桶的坐标、画幅及新旧状态。再 `g` 或 `a/0` 停止，保留33供下轮 `g`。不执行行走、发射或机构动作；已有上电舵机PWM并非断电。
3. **完善无机械臂流程32**：`App/mission_trial.c` 在R1后停稳等合法QR，不再固定等10秒；任务走廊2450按实测 `b1d` 拆成入口到桶、桶到下一转角。指定球仍在完整2450预算内寻找，不在桶位置提前截断。靶/人质对位若造成净后退，任务后补回原停车进度，再按同一里程账本计算余程，避免重复计距。抓放仍以10秒停车占位。
4. **补测试及交接材料**：新增/扩展33停止与写命令检查、十类二进制回放、32拆段与补回测试，以及 [VISION_TEAM_HANDOFF.md](VISION_TEAM_HANDOFF.md) 和 `tools/build_vision_handoff.py`。包内含视觉安装包、配套HEX、说明、二维码与回包模板。

既定31路线、编码器接线/轮位、轮速PI、航向参数、转向角度和速度定值没有因这次视觉适配改变。旧正式整场的四个标定闸门及 `BENCH_AUTO` 仍为0；不能把能编译理解成整场已放行。
