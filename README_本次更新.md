## 最终行为

- TaskSelection增加完整扫码帧检查：同一合法三位码连续3帧确认，空帧/非法码/不同码冲突/换码打断候选计数；确认前QR53为count0，确认后锁存回传。QrReader不再按QR_MAX裁剪确认输入，QR_MAX只限制显示。
- 独立运行仍默认IDLE，USER进入QR后确认任务，先发送确认的QR，下一轮释放旧图再自动切OBJECT。331只选择蓝球ID3、蓝靶ID7、圆柱ID1；支持全部27组合，独立画面及UART仅保留任务三类，不带桶。USER返回QR清空旧任务和候选；模型自动加载失败保留任务并留QR，允许USER重试。
- 每类选当前帧最高置信度且框有效的一个；丢失后不复用坐标。未扫码独立进入OBJECT只发空目标包，不发送黑桶或其他物体坐标。
- MCU接管优先：60/QR确认后继续扫码回传，等待主控请求；63仍按task/digit单目标，包括桶4/0→ID9，无需先有QR缓存。通用60/OBJECT诊断仍三任务加桶，未确认码时只选桶。接管后保留全类别诊断显示，触屏仅改变显示，不能改变UART筛选。
- 01/53/60/63/61/62布局、CRC、ACK门控和request_id绑定均保留，不引入05的ASCII协议。扫码时序新增连续3帧要求，主控按原协议等待有效QR，不需改解析器。
- 保留第36档1920×1440及中心50% ROI、9564十类模型、原字号/配色、触屏、USER长按退出、自动UART日志。元数据和日志版本同步2.1.6。
