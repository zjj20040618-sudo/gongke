## 改了什么

- `App/proto.c/.h`：接收视觉53短QR（合法三位1～3）、保留51历史兼容；新增63四阶段任务选择。接收必须匹配当前请求/ACK，晚帧或电控60/63请求回显不当成扫码。阶段结束仅关闭本地业务接收，不给视觉发IDLE停止；串口仍排空输入。
- `App/robot.c`：更新固件标识及诊断；既有UART错误/重启接收路径有主机回归。QR成功一次性通过蓝牙ASCII回传OK，而不是把画面有框当作成功。
- `App/test.c/.h`、`route_test_plan.h`：31上电/选择后请求QR，g只启动R1；R1结束且已收到合法三任务才进入R2，未收到则停车等待，不用10秒超时放行。保留33静止QR→OBJECT诊断。
- 31当前12步：左530/v100→后650/v100→左旋92°→前750/v300越障路→后170/v20→前210/v100→左730/v100→前780/v100→右旋90°→前2450/v100→右旋90°→前2125/v100。不执行视觉目标任务或机械动作。
- 新增34：共用上面整条12步和局部运动参数，只关闭本地QR接收、不请求/等待QR，不给相机发IDLE。34→g启动，再g/a/0取消整链；31扫码闸门保持不变。各段仍刹停、轮计数稳定250ms、软件重置航向零点、等750ms后再走；清零不等于校准IMU或自动摆正车身。
- 31局部acc700/dec350、ykp0.3、fff种子0.00625，小数轮速保留微小修正；实际RAM可改并自动回传。末端渐减速，手动g/a/0仍即时取消整链；fff0为本轮用户试验值之一，不虚称已定稿。
- `motion.c/.h`、`steps.c/.h`、`test_config.h`：柔停、显式航向增益及15～18方向/速度RAM增益。不同速度的ykp档不自动套进31/32，轮速PI、引脚/编码器映射未随本次上传改动。
- `mission_trial.c` 与三类正式任务文件：在准备球/转180后找桶/准备靶/准备人质时分别发63请求。32靶对齐后停稳1秒，激光2秒后关闭；球/桶/人质机械动作各停10秒占位。对位净后退补回后继续剩余道路预算，不额外重复整段。
- 保留队友最新视觉源码与9564模型；只更新配套接收器兼容测试，不改他的识别算法。新增电控给视觉的 [CONTROL_TO_VISION.md](CONTROL_TO_VISION.md)，同步协议/待办/导览。
