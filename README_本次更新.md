## 本次电控修改

- 球/人质正式入口与32共享`steps.c::step_align_xy`：先修图像X（车身前后），再修Y（车身左右），X又越界回修X；每帧检查两轴，不能把各自曾经到位算完成。换轴刹停、四轮静止250ms后用新图启动；同一目标两轴同时各±8px、连续5个新seq且静止250ms才通过。空包/错目标立即失效，300ms旧坐标刹停等新图，拒绝乱序及画幅变更。阈值/12～80mm/s为试验种子，未证明实体抓取余量。
- 32新增`bcy/hcy`和`ysg1/ysg2`，配合已有`bcx/hcx`及`vsg1/vsg2`，全部RAM-only且运行期锁定。正式表通过`step_grab_alignment_set`独立配置，默认未标定，32值不会自动写到正式表。MissionTask扩为2KB，IOC同步512words，诊断缓冲移出任务栈。
- 激光统一改为独立TB6612控制：PC12=STBY，PB9=TIM11 PWMA、PB0=AIN1、PB1=AIN2；轮电机PC8不变，旧PA15激光不再驱动。35仍只看X250～260，合格5新帧+停车1s后持续点亮，g/a/0或异常关闭；32/正式打靶仍是停车1s→激光2s→关闭。上电默认灭。
- 单STBY接法见[CONTROL_TUNING_TODO.md](CONTROL_TUNING_TODO.md)顶部：PC12只接STBY，PWMA/IN固定电平；3.3V成品激光必须有匹配的VCC/VM电源与共GND，GPIO不供电，AO1红/AO2黑，不将AO2另接GND。实际电压电流/点亮未在本轮验证。
- 31/34/36/37共享倒车越障：后退650/v300→前进80/v20靠板→后退190/v100离板。普通段启用航向、独立FFF/BFF/LFF/RFF和到距停稳纠角；越障/靠板关闭这些纠正，离板前停稳清航向等750ms。前FFF负、后BFF正是装臂后的小试验种子，横移路线槽默认0，不冒充已标定补偿。蓝牙帮助与真实配方数值已对齐。
