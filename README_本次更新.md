# 本次更新：逐个开关物体信息与手动十类识别

更新：2026-10-06。视觉基线d27f755，App2.1.7；当前分支vision-task-filter-20261006。本轮修改正式03视觉App、相关测试与交接文档。此前取消上传要求继续有效，仅本地构建和版本保存，不推送、部署或烧录。

## 最终行为

- 自动扫码/电控任务：任务目标信息默认显示，其他物体信息默认隐藏。所有本帧检测框和中心十字仍保留；点击其他物体显示信息、再次点击隐藏。点击任务目标隐藏信息、再次点击恢复。
- 每个物体分别记录开关，可以同时查看多个目标，同类不同实例也分别操作。长按不反复开关；点图像空白恢复当前模式默认值，点黑边不操作。
- 连续帧按同类别和框重叠关联开关，只显示本帧坐标。目标丢失清除它的开关，重新出现按默认值显示；快速移动或同类交叉不保证身份跟踪。
- 接管前USER手动切到OBJECT，不需要先扫码即可显示十类检测结果；START_MODE为OBJECT时同样默认全部。默认启动仍IDLE；电控接管后短按权限保持。
- 屏幕查看与UART筛选分开：独立UART只发送已确认三任务，无QR仍发空目标包；63仍只回指定目标，通用60/OBJECT仍按原三任务加桶诊断。隐藏任务信息不停止回传，显示其他物体也不混入回传。
- 成功的新请求或切模式清开关；同号重试保留。保留扫码连续3帧确认、9564模型、1920×1440扫码及中心ROI、字号配色、USER长按退出、UART日志和全部协议字段。未修改电控源码或用户config.py字号2。
