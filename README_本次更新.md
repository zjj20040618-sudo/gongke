# 本次更新：扫码区域可触屏移动

更新：2026-10-06。视觉基线fec13f4，App2.1.10，分支vision-task-filter-20261006。只改正式03视觉App、必要测试及交接，不动App/电控源码。保留用户物体字号2，仅本地构建与提交，不上传、不部署、不烧录。

## 怎么用

1. 在QR模式点击MC实体屏想放置扫码框中心的位置；黑边点击无效，靠边自动限位。移动的是实际扫描ROI，不只是显示线。
2. 当前位置只在App本次运行中保留，切模式/新请求不重置；重启恢复config.py的QR_ROI_CENTER_X/Y。默认均0.50；Y=0.35可把框上移，当前图幅对应[480,144,960,720]。QR_ROI_TOUCH_MOVE=False禁用触摸移动。
3. 每次实际移动打印[QR ROI]中心比例，可抄回config.py固定启动位置。保持完整二维码及白边在框内；QR_ROI_FRACTION为宽、高比例，0.50对应面积25%，1.0为全图且不可移动。
4. 移动清掉旧显示缓存和未确认码的连续帧计数，不修改已锁存任务。仍需同一合法三码连续3帧；触屏不改任务筛选、黑桶当前帧持续发送、ACK/请求绑定或包格式。200毫秒仅显示暂留和OBJECT独立信息开关保持。

## 原07与正式版差异核对

只读检查回收站07源码，未恢复/修改已删除工程。第36档两版请求1920×1440、ZBAR和中央宽高50%相同；旧07直接灰度采集，正式RGB采集；旧07任意码单帧解出即记成功，正式合法三位1..3且连续3帧才锁定。07切分辨率后丢2帧，正式没有。

间歇解码在旧测试算成功、正式不能锁定，能解释部分观感差异；灰度/采集差异是否降低真实解码率尚未证实，不能凭手机拍屏归因焦距、曝光或像素。未擅自降确认门槛、转换采集格式或改硬件参数。App README“为什么36档移植后感觉远近范围变小”记录定位步骤和证据边界。
