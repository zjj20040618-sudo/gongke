更新：2026-10-06。视觉基线0bec766，App2.1.9；当前分支vision-task-filter-20261006。只改正式03视觉App、测试及交接。保留用户物体字号2，仅本地提交/构建，不上传、不部署、不烧录。

## 行为与循环

- 新增OBJECT_BOX_HOLD_MS=200：本帧命中立即更新框，漏检后按最后命中时间最多暂留200毫秒；持续漏检不续期。0关闭暂留。没有sleep或降低推理/串口刷新频率，每轮推理后才刷新画面。
- 只复制框的数值用于UI，不保存旧图片。暂留信息加HOLD标记；多个物体独立计时，同类框用重叠位置关联，不承诺运动预测或精确身份跟踪。
- 保留逐个开关信息：短时漏检维持开关，框从画面消失后清开关；新任务/成功切模式/图幅变化清缓存，同号请求重试保留。
- 实际顺序仍读原图、detect、TaskSelection、UART、显示缓存/触摸、画框显示；当前DUAL_BUFFER=False。未把注释、框或文字送入模型，未启用异步/双缓冲。
- UART只使用本次推理原结果。即使屏幕有暂留桶框，桶漏检同一帧仍发送空目标包；重新命中立即发新坐标。协议字段、CRC、ACK和request_id不变，电控无需改解析器。
- 防闪烁只改善显示，不提高识别率或FPS。不能在一次阻塞detect中途更新屏幕；快速移动可能短时留旧框。双缓冲流水线和上一帧结果对应问题另见App README“画框防闪烁与实际循环”。
