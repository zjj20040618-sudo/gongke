## 改动和范围

追加显示补丁（基线e59c004，独立本地提交）：`OBJECT_TEXT_SCALE=3`单独控制物体字号，扫码`BOX_TEXT_SCALE=2`不变；十类使用不同框色及同色实心标签底板，黑色实心字显示类别/置信度和中心X/Y。窄屏、长行或拥挤时允许缩字，保留现有标签避让与触屏单选。未改模型、检测、UART或协议。当前工作区124项视觉测试、7项主循环测试通过；2.1.5包重新核对并构建。只保存本地Git与安装包，不推送、不部署设备。

- ui.py测量文字/底色后按占用矩形避让；先画全部框再画文字。附近无空位时最多3次缩字，仍放不下只保留框，防止文字硬重叠。单选详情保留类别、置信度、中心X/Y及w/h。
- 新touch_inspector.py非阻塞读取MC触屏，每轮最多8事件，只处理按下沿。按FIT_CONTAIN把屏幕点映射到实际图像；点框单选、点空白全显、黑边忽略。每帧同类IoU>=0.2关联位置；丢失显示LOST，不恢复旧坐标或自动跳到同类。交叉/快速移动不保证身份跟踪。
- main.py在UART发送完成后独立选择显示对象，不改变TaskSelection或组包。新请求/模式切换清选择，同号重试保留；IDLE/QR/ACK等待也消费事件，触屏故障恢复全显，退出/初始化失败释放资源。
- 模型9564、十类顺序、阈值、黑桶任务每帧回传、ACK门控及全部协议字节不变。QR仍36档1920×1440、中心50% ROI；不需改电控解析器。
- App元数据、设备日志头2.1.5，打包清单新增touch_inspector.py；旧包/模型/USER长按/自动日志保留。
