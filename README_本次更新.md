# 本次更新：USER 长按允许人为退出

更新：2026-10-05。仅修改视觉 App 的退出条件、按键提示与相关测试/说明；电控源码、模型、协议字节、筛选、短按切模式权限均不变。

## 改动与安全边界

- USER 长按1.5秒：接管前后都允许退出，即使ACK正在重试；旧的 `not control.remote_owned` 退出条件保留为注释，便于对照。
- USER 短按：仍只能在电控接管前切QR/OBJECT模式。长按优先；退出后不再新取图/发业务，执行已有资源清理。
- 在主循环下一次处理按键时退出；不能同步打断正在执行的模型加载/推理。未新增退出通知、停止指令或尾帧送达保证，视觉退出不代表电机已停。电控须独立提供急停/断流保护，本轮不改其运动逻辑。
